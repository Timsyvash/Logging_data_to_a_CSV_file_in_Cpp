# Logging Data to a CSV File in C++ (ESP8266 IoT Logger)

Модуль автономного логування даних із датчиків (DHT11/DHT22) у **CSV-файл** на базі файлової системи **LittleFS** для мікроконтролера **ESP8266 (Wemos D1 mini)**, розроблений на C++ за допомогою **PlatformIO**. 

Проєкт реалізує безпечний фоновий запис телеметрії без блокування основного циклу, механізм ротації файлів для захисту Flash-пам'яті від переповнення та повний REST API для керування логами через веб-інтерфейс.

---

## 🚀 Основні можливості

* **Неблокуюче логування:** Запис даних за допомогою системних таймерів (`millis()`) із заданим інтервалом (наприклад, раз на хвилину).
* **Автоматична ротація файлів:** Контроль максимального розміру CSV-файлу (`MAX_LOG_SIZE`) із автоматичним перенесенням старих даних у резервну копію (`/datalog_old.csv`), що запобігає заповненню розділу LittleFS.
* **REST API для керування сховищем:**
  * Скачування актуальних та архівних логів у форматі `.csv`.
  * Динамічне сканування файлів (`/api/files`) у форматі JSON.
  * Безпечне видалення файлів через вебпанель.
* **SPA Веб-інтерфейс:** Сучасний дашборд із живим графіком (Chart.js) та вбудованим файловим менеджером[cite: 1].
